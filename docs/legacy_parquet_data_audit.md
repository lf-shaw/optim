# 旧 tuda2 数据的新版多期 LP 测试

2026-09-10，只读访问 `/mnt/e/works/5.data/tuda2/basic`，未迁移或修改源库。
按年份选择 Parquet 文件，再使用 dt 谓词裁剪至 2020-07-01—2020-08-31。

## 数据与实验边界

- 44 个风险交易日，完整风险数据覆盖的每日样本 3864–3959 只股票。
- 使用 `risk/barra/exposure`、`cov`、`barra_spec`。按协方差当日因子行对齐；
  行业类别展开，country 补常数 1；股票敞口与特异风险严格对齐。
- 该旧库风险数据不是原始 DataYes 百分数口径。2020-07-01 使用存储的 cov 和 spec_risk
  重建个股总风险，与存储 total_risk 的绝对差中位数约 `7.0e-6`，最大约 `4.1e-5`。
  本次不重复缩放或年化；测试仅为 LP，不用其风险数值证明 TE 预算求解结论。
- 剔除风险数值不完整的 23 条日期/股票记录，显式限定测试样本；不是优化器自动忽略缺失。
- `quote/universe/csiall` 的 status=1 作为可交易，其余状态不可交易，保留 1377 条
  不可交易日期/股票记录。缺失状态报错，不自动视为可交易。
- 找到 csi300/csi1000 的成员标记，但未找到正式指数权重。本次使用有效样本内的成员等权，
  **不是官方指数权重**。alpha 为固定种子 20260910 的合成标准正态分数，分别测试
  固定股票分数与每日独立分数；不声称复现生产 alpha。
- 使用旧库 `quote/rtn/d1` 的 `rtn` 推进每日持仓，不使用零收益对照，不填补缺失。
  首期不传持仓并按默认免换手建仓，其后真实收益漂移、前一期结果衔接。
- 约束与当前用户 LP 参数一致：主动 0.004、总主动 1.8、换手 0.05、风格 ±0.3、
  size ±0.2、行业 ±0.01，无风险预算和成分股持仓下限。

## 完整入口结果

使用新版 `optimize_range`，当前工作区源码。每种情形两轮，第二轮反转后端顺序。
下表为第二轮完整入口尝试吞吐；包含预检和逐日组装，不包含读取/转换原始文件。
每轮都是 44 optimal，没有通过跳过不可行期提高速度。不开 profiler 或进度条。

| 成员等权测试基准 | 合成 alpha | auto / HiGHS（期/秒） | MOSEK（期/秒） |
|---|---|---:|---:|
| csi300 | 固定股票分数 | 14.63 | 10.97 |
| csi300 | 每日独立分数 | 13.35 | 10.69 |
| csi1000 | 固定股票分数 | 12.04 | 7.23 |
| csi1000 | 每日独立分数 | 10.82 | 6.44 |

MOSEK 实际 14 线程。第二轮每日准备约 23–32 ms，逐期数据物化约 1.4–1.6 ms。
这些结果增加了真实收益、停牌状态和不同成员规模的覆盖，但**仍未复现生产 prepare
278 ms/期**。旧年份的资产规模较小、等权测试基准和合成 alpha、源码运行环境均与生产
不同，不能用上述吞吐否认生产瓶颈，也不能当作正式指数回测性能承诺。
