# 当前后端路线（2026-09-09）

本说明替代历史报告中的 PIQP 前沿搜索和商业自动回退设计；历史性能记录保留用于审计，
不代表当前默认实现。

| 问题类型 | auto 主后端 | 失败后的行为 |
|---|---|---|
| LP | HiGHS | 返回状态 |
| QP | direct PIQP | Clarabel 独立复核，仍失败则返回状态 |
| Factor-QCQP（风险预算转换为 SOCP） | Clarabel / QDLDL | 返回状态，不重复求解或调用 MOSEK |

只有用户显式指定 `SolverPolicy(backend="mosek")` 才调用 MOSEK。
未安装、没有可用授权或授权过期抛出 `RuntimeError`，不切换后端；普通数值失败和不可行
仍返回标准结果。授权判定使用 MOSEK 原生错误码及异常链，不解析日志或手工解析 license。
单期、多期、显式诊断使用同一路由契约。诊断默认 auto，不继承原问题的 MOSEK 选择。

显式 `backend="clarabel"`、`"mosek"` 仍支持 LP/QP/Factor-QCQP，不预筛、不回退。
`lp_prescreen` 保留且默认关闭；手动打开时，风险预算问题的外层 LP 最优点如通过验收
则直接返回，否则直接转 Clarabel，绝不进入参数搜索。

## 删除范围与边界

- 删除运行时参数 QP 搜索模块、相关成功证书分支，以及商业自动回退配置。
- 删除 `theta_seed` 单期参数、结果字段、序列字段及上一期参数传播。
- 删除搜索初值、扩张、最大次数、搜索中间容差等配置；旧参数报错而非静默忽略。
- Clarabel / MOSEK 共享的因子变量扩展迁移到 `factor_conic.py`，只扩展线性域，
  不再为了锥问题构造无用的风险 QP Hessian。
- 编译清单同步移除旧模块；core ABI 升为 2，复现包格式升为 2。
  v1 复现包不再直接加载，需在原版本提取业务输入，再用新版重建问题与策略并导出 v2；
  原版本直接重新导出仍是 v1。本次未覆盖用户原有复现文件。
- 科研 benchmark 和历史报告不属于运行时库，也不进入 wheel；历史材料不删除。

## 验证

源码回归覆盖 LP/QP/风险预算、序列、诊断、复现、默认禁用 MOSEK、实际缺授权、
包装后的原生授权过期码及旧参数拒绝。缺授权测试使用独立进程，避免 Fusion
在进程内缓存已签出的授权导致假阳性。

已完成全量源码回归（258 项通过，1 项可选 CVXOPT 模块跳过；独立环境补测原型 12 项通过）、Cython wheel 编译、
10 个 core 扩展及公共资源校验，以及脱离源码目录的安装冒烟；确认二进制默认路线为
`highs` / `piqp` / `clarabel_qdldl`。依赖环境与计时详见同期实验报告。

此次包含公共参数和复现格式的不兼容变更；提交不等于发布，不自动创建 tag 或上传 wheel。

真实 `pp` 的数值模型复测，单线程，每组四次取后三次中位数：

| 场景 | 状态 | auto 路线 | 秒/次 |
|---|---|---|---:|
| 原始 2% TE + 5% 换手率 | infeasible | Clarabel | 0.484 |
| 去换手率，2% TE | optimal | Clarabel | 0.358 |
| 去换手率，6% TE | optimal | Clarabel | 0.639 |
| 去风险预算及换手率，LP | optimal | HiGHS | 0.156 |
| 去换手率，默认风险厌恶系数 QP | optimal | PIQP | 0.227 |

本次旧 `pp` 仅通过内部数据解码读取 problem，不恢复已经删除的旧 policy；
没有改变公开 `load_repro` 的版本拒绝规则。QP 此处为默认风险厌恶系数，
不同于 DYOPT 对照中的系数 10，不应直接当作那一案例的计时。

新的热启动研究与本改造分开评估；不会恢复旧参数搜索，也不改变持仓自然漂移的业务语义。
