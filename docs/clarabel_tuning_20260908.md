# Clarabel 使用方式优化实验（2026-09-08）

历史实验基于 `0b832f4` 时的运行时实现与 v1 复现包。后续默认路线及复现格式已变更；
重现本文原始统计请使用该版本，或迁移为 v2 输入后重新测试，勿混用两轮结果。

## 结论与适用范围

这轮先做等价表述和参数对照，不以单个案例的最短时间修改默认参数。
主实验中，当前配置已相当接近这些候选的最好平均表现；未发现稳定、显著、同时保持
可靠性的加速方案。因此暂不修改生产 Clarabel 默认值，也不扩大公共 API。

固定变量消元在部分案例上有收益，但总体收益不稳定，尚不足以支持引入额外的原生证书
逆映射和生命周期维护逻辑。实验实现仅保留在基准脚本中，不是可发布的后端实现。

## 样本与方法

- 复现包：`tmp/pp.tar.gz`，使用 `load_repro` 读取，不按文件扩展名解压。
- 三个复现问题：原问题（不可行）、仅去掉换手率（2% TE）、去掉换手率并改为 6% TE。
- v5 均匀抽取 2025-05-06、05-16、05-29、06-11、06-24；每个日期分别测试 2% 和 6% TE。
- v5 是独立冷启动：按已有适配器，固定种子 20260826，在按权重排序的前 500–600 只
  股票中确定持仓数量，使用该日前 N 只股票归一化。不是链式持仓实验。
- v5 主动权重上限 1%，行业偏离 5%，全部风格偏离 0.6，L1 换手上限 5%，基准成分股
  权重下限 81%，总主动权重上限 1.8；风险数据转换为年化小数单位。
- 所有候选通过同一公共 `PortfolioOptimizer.solve` 路径；可行候选继续经过原问题独立验收。
- 预热一次后，固定种子 20260908 随机排列配置顺序，每个问题/配置重复三次。
- 共 13 个问题 × 11 个配置 × 3 轮 = 429 次正式求解。
- 不导出权重；保留状态、原始 alpha 目标、gap、最大约束残差、迭代数、setup/solve/端到端耗时。
- 环境：开发机 WSL2，Python 3.11.11、NumPy 2.2.1、Clarabel 0.11.1。

以下是开发机结果，不能与以前生产机的秒数直接拼接。小于几个百分点的差异可能包含
运行噪声；三次重复不足以评价 P99，也不是对全部回测区间的性能保证。

## 主实验结果

表中为全部 39 次运行的算术均值，包括不可行样本；风险归一化行含数值错误，不能按更快的
失败返回当作优化成功。

| 配置 | 端到端均值/s | 后端 solve 均值/s | 平均迭代数 | 状态（39 次） |
|---|---:|---:|---:|---|
| 当前基线 | 0.2956 | 0.1899 | 22.69 | 36 optimal / 3 infeasible |
| FAER | 0.3043 | 0.1958 | 22.69 | 同基线 |
| 仅 gap 容差改为 1e-6 | 0.2896 | 0.1867 | 22.46 | 同基线 |
| gap / feas 均改为 1e-7 | 0.3033 | 0.1946 | 22.31 | 同基线 |
| gap / feas 均改为 1e-6 | 0.2927 | 0.1867 | 21.77 | 同基线 |
| 最大步长比例 0.999 | 0.3285 | 0.2226 | 26.08 | 同基线 |
| 风险锥按预算归一化 | 0.3052 | 0.2122 | 25.46 | 36 optimal / 3 numerical_error |
| 固定变量双边界合并等式 | 0.3000 | 0.1951 | 23.15 | 同基线 |
| 固定变量代入消元 | 0.3007 | 0.1899 | 22.69 | 同基线 |
| alpha 缩放目标从 0.2 改为 2 | 0.4198 | 0.3094 | 37.23 | 同基线 |
| alpha 缩放目标从 0.2 改为 0.02 | 0.3779 | 0.2744 | 33.00 | 同基线 |

### 精度与目标尺度

仅放宽 gap 的端到端均值改善约 2%，平均迭代数只下降 0.23。
同时放宽 gap / feas 到 1e-6 后，最大验收残差由约 1.83e-7 增至 6.08e-6；
虽然本批仍通过验收，但平均时间改善不足 1%，没有理由作为默认值。

`gap6` 实验修改的是缩放后目标的 Clarabel 原生容差，不是用户业务允许的 alpha 损失。
输出的 `gap` 则取公共结果中的原始目标单位数值证书。改变 alpha 缩放时，原生绝对
容差对应的原始目标精度也随之变化；不能把该实验说成固定原始精度下的纯线性代数比较。
所有变体均保留现有独立验收和清理策略，没有通过关闭验收获得速度。

### 固定资产：局部收益不等于普遍收益

复现问题有 333 个固定变量。6% TE 派生问题中，消元的端到端中位数从 0.6684 s 降至
0.6067 s，约快 9.2%；求解迭代从 56 降至 55。
但 2% TE 派生问题从 0.3774 s 变为 0.3885 s，没有改善。
v5 样本没有固定变量，消元不提供规模收益，反而承担检查/切片开销。

实验消元保留原锥行，仅替换固定列并让求解器处理常数行；它不是完整的组合专用 presolver。
因此结果也不能证明所有更深入的消元策略都无效。

`fixed_equal` 和 `eliminate` 尚未完成原生不可行证书坐标回映射，脚本明确标为
`diagnostic_mapping_valid=false`。它们的可行候选在原问题上验收，但不得将其原生贡献表
当作完成逆映射的诊断结果。正因为这部分维护成本，不以一个案例的局部收益贸然引入生产。

### 风险锥缩放

正比例缩放在数学上等价：

$$
\|Ra\|_2\le r
\quad\Longleftrightarrow\quad
\|Ra/r\|_2\le 1,\qquad r>0.
$$

但原不可行样本三次都从 `infeasible` 变成 `numerical_error`。
因此不能把这个变体作为生产优化，即使某些可行案例更快。

## 复测入口

### 补充：三角风险平方根

另做 13 个问题 × 2 个配置 × 3 轮 = 78 次独立交错对照，以 Cholesky 三角平方根替换
当前特征分解平方根；协方差非正定时仍使用原表示。两种表述均保持
$R^{\mathsf T}R=F$（浮点误差范围内），不改变风险定义。

基线/三角平方根的端到端均值分别为 0.2795 / 0.2773 s，仅改善约 0.8%；
solve 均值为 0.1774 / 0.1730 s。两者均为 36 optimal / 3 infeasible。
6% TE 复现问题反而从 56 次迭代变为 57 次。此项也未提升为生产默认。
这组有独立基线，不能拿它与前一组的绝对秒数直接计算收益。

```bash
python benchmarks/clarabel_tuning.py \
  --rounds 3 --v5-dates 5 --variants baseline,chol \
  --output tmp/clarabel_tuning_chol.json
```

### 主实验命令

```bash
python benchmarks/clarabel_tuning.py \
  --repro tmp/pp.tar.gz \
  --rounds 3 --v5-dates 5 \
  --output tmp/clarabel_tuning_final.json
```

只测试复现包：省略 `--v5-dates`。`--variants` 可指定逗号分隔的配置子集。
v5 路径由已有 `frontend_prepare_v5_real.py` 的默认值提供；该适配器仅用于开发测试，
不是新增生产数据接口。脚本使用进程内 patch，必须单进程串行执行，不能嵌入生产服务。

主实验逐次记录位于 `tmp/clarabel_tuning_final.json`，不含持仓。
本次未改变 auto 路由、PIQP、MOSEK 或 Clarabel 默认容差和线性求解器。

后端选择、不可行对偶下界、编译及后端回归：72 项测试通过。
